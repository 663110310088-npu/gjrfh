# จับโป๊ะ! (สำนวนคดีโกหก)

เกมปาร์ตี้ทายคนโกหก เล่นแบบรวมกลุ่ม 4-10 คน ไม่ต้องใช้เน็ต เปิด index.html ได้เลย

## วิธีเล่น
1. กรอกจำนวนผู้เล่น (4-10) แล้วตั้งชื่อ
2. เลือกว่าใครเป็น "คนทาย" ของรอบนี้
3. ทุกคนอ่านคำถามพร้อมกัน (รวมถึงคนทาย)
4. คนทายเดินออกไป/หลับตา แล้วผู้เล่นที่เหลือกดสุ่มว่าใครต้อง "พูดความจริง"
   - คนอื่นที่เหลือทั้งหมดคือ "คนโกหก" ต้องแต่งเรื่องให้สมจริง
5. คนทายกลับเข้ามา ฟังทุกคนตอบคำถามแบบจริง-ลวงปนกัน
6. คนทายเลือกคนที่คิดว่าโกหกทีละคน
   - เจอคนโกหก: +1 คะแนน เลือกจะหยุดเก็บคะแนน หรือเปิดต่อลุ้นเพิ่ม
   - เจอคนพูดจริง: พลาดทันที ได้ 0 คะแนนรอบนั้น
   - จับคนโกหกได้ครบทุกคน: ได้คะแนนเต็ม
7. จบรอบแล้วจะมีหน้า "เฉลยคดี" เล่าเรื่องจริงที่เกิดขึ้นให้ทุกคนอ่านพร้อมกัน (ยาวขึ้นกว่าตัวคำถามเพื่อให้เห็นภาพว่าทำไมคำตอบถึงเป็นแบบนั้น)

## คะแนน
- คนทาย: เท่ากับจำนวนคนโกหกที่เปิดเจอ (เป็น 0 ถ้าพลาดไปโดนคนพูดจริง)
- คนพูดความจริง: เท่ากับจำนวนคนโกหกที่ "ไม่โดนจับ"
- คนพูดโกหกที่รอด: เท่ากับจำนวนคนโกหกคนอื่นที่โดนจับได้ในรอบนั้น
- คนพูดโกหกที่โดนจับ: ได้ 0 คะแนนทันที

คะแนนสะสมไปเรื่อย ๆ ทุกรอบ เลือกคนทายใหม่ได้ทุกรอบ กด "จบเกม" เมื่อไหร่ก็ได้เพื่อดูอันดับสุดท้าย

## คำถาม / เรื่องราว
มีคำถามแปลก ๆ 69 ข้อ ฝังอยู่ในไฟล์ index.html (เดิมคือ questions.json) แต่ละข้อมีสตอรี่เบื้องหลังที่เขียนให้ยาวและมีรายละเอียดมากขึ้น อ่านจบในหน้า "เฉลยคดี" หลังจบแต่ละรอบ
หากต้องการแก้ไข/เพิ่มคำถามเอง ให้แก้ตัวแปร QUESTIONS ในแท็ก <script> ของ index.html โดยแต่ละข้อมีรูปแบบ:
{"id":1,"question":"...?","answer":"...","story":"..."}

## ดีไซน์
หน้าตาเกมออกแบบธีม "สำนวนคดี/dossier" โทนเข้ม กระดาษสีน้ำตาลอ่อน ตรายาง และโทนสีสนิม-เขียวทะเล ให้เข้ากับธีมการ "จับโป๊ะ/สืบคดี"
